# AFEOL-RELC — December 2025 draft withdrawn

The previous model at this path contains a public-hint disclosure of message
bits, an ineffective correction, and unsupported correctness/security claims.
It must not be used as a secure encryption design.

The proposed replacement is [Draft 0.2](RELC_Specification_v0.2_Draft.md).
It provides an explicit deterministic decryption-correctness proof for a new
research profile. It does not establish cryptographic security.

The original document remains available in Git history at commit
`c1fd865ba7300c03d1aa3fe4b40ceab0b0741adf`.
